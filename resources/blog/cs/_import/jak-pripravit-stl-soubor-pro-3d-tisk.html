Připravujete svůj první 3D tisk a nevíte, jak správně exportovat STL soubor? Nebo se vám tisk nedaří kvůli chybám v modelu? Tento průvodce vás provede celým procesem — od exportu z CAD programu až po finální kontrolu před tiskem.

Špatně připravený STL soubor je nejčastější příčina neúspěšného 3D tisku. Stačí pár minut navíc při přípravě a ušetříte si hodiny ladění, plýtvání materiálem a frustrace.

Co je STL soubor?

STL (STereoLithography) je formát souboru, který popisuje 3D geometrii pomocí trojúhelníkových plošek. Jde o standardní formát pro 3D tisk — rozumí mu prakticky každý slicer i 3D tiskárna na světě.

Pouze geometrie
Žádné barvy, textury ani materiály

Trojúhelníková síť
Mesh ze stovek tisíc plošek

Binární STL
Menší velikost, rychlejší načítání

Univerzální
Podporovaný všemi slicery

Krok 1: Export STL souboru z CAD programu

Fusion 360

  1. Pravé tlačítko na model
  2. Vyberte Save As Mesh
  3. Formát: STL (Binary)
  4. Refinement: High nebo Medium

Tinkercad

  1. Klikněte na Export vpravo nahoře
  2. Vyberte .STL
  3. Soubor se stáhne automaticky

SolidWorks

  1. File → Save As
  2. Typ souboru: STL (*.stl)
  3. Options → Resolution: Fine
  4. Jednotky: Millimeters

Blender

  1. File → Export → STL
  2. Zaškrtněte Selection Only
  3. Forward: Y Forward, Up: Z Up
  4. Scale: 1.00

FreeCAD

  1. Vyberte objekt
  2. File → Export
  3. Formát: STL Mesh (*.stl)

Krok 4: Kontrola rozměrů a orientace

Jednotky a měřítko

STL formát neukládá jednotky — slicer předpokládá milimetry. Pokud váš model vyšel v palcích nebo centimetrech, bude tisk extrémně malý nebo velký. Vždy zkontrolujte v sliceru.

Orientace modelu

  • Nejdetailnější strana nahoru
  • Plochá strana dolů
  • Minimalizujte převisy nad 45°
  • Síly zatížení napříč vrstvami

Krok 5: Příprava ve sliceru

Nejpoužívanější slicery: PrusaSlicer, Cura, Bambu Studio, OrcaSlicer

Často kladené otázky

Jaký je rozdíl mezi STL a 3MF?

3MF je modernější formát, který uchovává barvy, materiály i metadata. Pro běžný tisk stačí STL, pro multibarevný tisk je výhodnější 3MF.

Jak velký by měl být STL soubor?

Pro běžný tisk obvykle 5–50 MB. Soubor přes 100 MB má pravděpodobně zbytečně vysoké rozlišení.

Můžu STL přímo poslat do tiskárny?

Ne, STL musí projít slicerem, který ho převede na G-kód — instrukce pro tiskárnu.

Co dělat, když nemám CAD program?

Použijte zdarma: Tinkercad (online, jednoduchý), Fusion 360 (nekomerční použití), FreeCAD (open source) nebo Blender (organické tvary).

Potřebujete pomoct s přípravou nebo tiskem?
